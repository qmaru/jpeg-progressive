# jpeg-progressive

+ [Progressive JPEG](https://qmaru.github.io/jpeg-progressive/index.html)

+ [Masonry Demo](https://qmaru.github.io/jpeg-progressive/masonry.html)

All images are converted from PNG.

Keep the same size as much as possible.

+ PNG to JXL via [libjxl](https://github.com/libjxl/libjxl) (cjxl v0.11.0)

> Starting from Chrome 145, JXL can be enabled via: chrome://flags/#enable-jxl-image-format
